# Bhunte AI (भुन्टे)

A simple, Nepali-first point-of-sale app for small shops — sell by tapping pictures or scanning barcodes, add stock by photographing the wholesaler's bill, keep the udharo (credit) book by voice.

Android · iOS · Web — built with Flutter and Firebase.

> Status: Phase 1. The Flutter app runs on demo data; Firebase and AI services are stubbed.

## Run the app

```bash
cd app && flutter pub get && flutter run
```
